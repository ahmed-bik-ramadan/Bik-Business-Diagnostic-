# تشغيل حزمة BIK في مساحة العمل

الحزمة النشطة `@workspace/bik-platform` في `artifacts/bik-platform`. استخدم pnpm من جذر مساحة العمل مع ملف القفل والقائمة المركزية للاعتماديات:

```bash
pnpm install --frozen-lockfile
pnpm --filter @workspace/bik-platform run dev
```

يشغّل الأمر `tsx server.ts`؛ المنفذ الافتراضي 3000 ويمكن ضبط `PORT`. للبناء والتشغيل الإنتاجي استخدم `pnpm --filter @workspace/bik-platform run build` ثم `pnpm --filter @workspace/bik-platform run start`. يحتاج اختبار الخطوط إلى `dist`، ولذلك ابنِ الحزمة قبل أول تشغيل كامل لاختباراتها في مساحة نظيفة.

التقرير وصفحات المراجعة وحاسبة الكلفة تُولّد في المتصفح دون نموذج. التخزين التشخيصي في جلسة المتصفح، مع وظائف استرداد وتقدم إرسال وتفضيل بلد موروثة في `localStorage`. لا يحتفظ الخادم بإجابات أو تقارير أو بيانات تواصل أو نصوص محادثة، ولا يحتاج إلى قاعدة بيانات.

المحادثة اختيارية: يصل إلى BIK سجل الرسائل المنقح والقطاع والمحاور وحالاتها و`mode` ومؤشرا النتيجة والترشيح. يرسل المعالج إلى المزود نص النظام وسجل الرسائل؛ نوع البداية يؤثر في العرض المرشح ولا يخرج كحقل مستقل. لا تُرفق بيانات الهوية المخزنة أو الإجابات الخام أو مبالغ التشخيص. المفتاح `OPENROUTER_API_KEY` خادمي فقط؛ غيابه لا يعطل التشخيص.

الخطوط مستضافة ذاتياً من حزم Fontsource داخل `dist/assets` ولا تُحمّل من Google. راجع [CURRENT_RUNTIME.md](./CURRENT_RUNTIME.md) لعقد البيانات وحدود الإثبات. لا تُعامل ملفات PostgreSQL والإدارة القديمة على أنها إعداد للتشغيل الحالي.
