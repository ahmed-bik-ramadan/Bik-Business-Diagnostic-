# منصة BIK — التشغيل الحالي v13

تطبيق عربي RTL لتشخيص الشركات وفق قواعد وحسابات ثابتة داخل المتصفح. صفحات المراجعة والتقرير وحاسبة تغطية كلفة العرض لا تستخدم نموذجاً آلياً. المحادثة الآلية الاختيارية بعد النتيجة منفصلة عن توليد التشخيص.

## البنية والبيانات

- الواجهة React وVite، والخادم النشط هو `server.ts` في هذه الحزمة. يخدم Express الواجهة ومسارات BIK تحت `/_bik-api`، مع تحويلها داخلياً إلى `/api`.
- يولّد `src/services/diagnose.ts` التقرير في المتصفح. لا يرسل هذا المسار إجابات التشخيص إلى خادم BIK أو إلى مزود نموذج.
- وضع التخزين النشط `session_only`، مع `CLIENT_DATA_STORAGE_DISABLED = true`. لا يحتفظ الخادم بإجابات أو تقارير أو بيانات تواصل أو محتوى محادثة، ولا يهيئ قاعدة بيانات. مسارات حفظ الإجابات وتوليد التشخيص القديمة واستقبال بيانات التواصل والأحداث مغلقة، والإدارة غير مفعلة.
- يحفظ المخزن الحالة التشخيصية في `sessionStorage`. `startMode` محصور في `analysis` أو `crisis`، ويعود إلى `analysis` عند البدء من جديد. إيراد الحاسبة يعيش في حالة المكوّن وحدها ولا يُحفظ أو يُرسل.
- توجد وظائف موروثة في المتصفح لاسترداد التقرير وتقدم إرسال أجزائه وتفضيل البلد عبر `localStorage`. تُزال نسخة الاسترداد عند اكتمال تأكيد الإرسال؛ لا يعني `session_only` أن كل مفاتيح المتصفح مؤقتة.
- تفتح مشاركة واتساب رسالة جاهزة من جهاز الزائر. الزائر يرسلها ويؤكد إرسال الأجزاء؛ لا يستقبل التطبيق إيصال وصول من واتساب أو من المستشار.
- الخطان Noto Sans Arabic وNoto Naskh Arabic مستضافان ضمن ملفات البناء من حزم Fontsource، مع `font-display: swap`. لا تُحمّل الخطوط من Google.

## المحادثة الاختيارية

يرسل المتصفح إلى مسار المحادثة سجل الرسائل المنقح وسياقاً ضمن قائمة بيضاء: القطاع، أسماء المحاور وحالاتها، `mode` الاختياري، و`overallComputed` و`lossSustainsExecutive`. لا تُرفق حقول الاسم أو الشركة أو الهاتف أو البلد أو المدينة أو الإجابات الخام أو مبالغ التشخيص. يرفض الخادم أي `mode` غير `analysis` أو `crisis` ويتجاهل الحقول غير المصرح بها.

يرسل `server/chatHandler.ts` إلى المزود نص النظام الذي يبنيه `buildChatSystemPrompt` ثم سجل الرسائل المنقح. يتضمن نص النظام القطاع والمحاور وحالة احتساب النتيجة والعرض المرشح. يؤثر `mode` ومؤشر الخسارة في الترشيح؛ لا يرسل المعالج كائن السياق الخام ولا حقلاً مستقلاً باسم `mode` إلى المزود. النص الحر يُنقّح آلياً لكنه لا يبرر وعداً باكتشاف كل بيانات شخصية؛ لا تُكتب بيانات شخصية في الرسائل.

تحتاج المحادثة الفعلية إلى `OPENROUTER_API_KEY` على الخادم؛ وعند غيابه تعيد عدم التوفر. `OPENROUTER_MODEL` اختياري. لا توضع المفاتيح في الواجهة. وضع `BIK_CHAT_MOCK=1` مخصص للاختبار خارج الإنتاج ويعيد رداً معلماً بلا اتصال بمزود.

## التشغيل والتحقق

تُشغّل الأوامر من جذر مساحة العمل التي تضم `pnpm-workspace.yaml` و`pnpm-lock.yaml` وهذه الحزمة في `artifacts/bik-platform`، باستخدام Node.js وpnpm المتوافقين مع اعتمادياتها:

```bash
pnpm install --frozen-lockfile
pnpm --filter @workspace/bik-platform run dev
```

المنفذ الافتراضي 3000، ويمكن ضبطه عبر `PORT`. للتحقق والبناء:

```bash
pnpm --filter @workspace/bik-platform run typecheck
pnpm --filter @workspace/bik-platform run build
pnpm --filter @workspace/bik-platform run test
pnpm --filter @workspace/bik-platform run start
```

يُنفذ البناء قبل الاختبار في مساحة نظيفة لأن اختبار الخطوط يفحص `dist` فعلياً. لا يحتاج التشخيص إلى مفتاح نموذج أو `DATABASE_URL`.

## حدود الطلبات والوكيل العكسي

`TRUST_PROXY_HOPS` يحدد عدد قفزات الوكيل التي يثق بها Express عند حساب `req.ip`. القيمة الافتراضية `1` كما كانت؛ يمكن ضبط `0` لاتصال مباشر أو عدد صحيح غير سالب يطابق بنية الوكيل الفعلية، مثل `TRUST_PROXY_HOPS=2`. القيم غير الصحيحة تعود إلى `1`. يجب أن يطابق العدد الوكلاء الموثوقين فعلاً، وأن يزيل الوكيل الموثوق ترويسات العناوين الواردة أو يستبدلها؛ يعتمد التطبيق `req.ip` بعد تطبيق إعداد Express.

الإعدادات التشغيلية في `server/runtimeConfig.ts`: ستون طلباً عاماً لكل IP خلال عشر دقائق، وقاطع طوارئ عام قدره عشرة أضعافها (ستمائة طلب مؤهل خلال النافذة). الطلب الذي حُظر لبلوغه سقف IP لا يستهلك القاطع العام. يبقى حد الدردشة عشرين طلباً لكل IP خلال عشر دقائق. المسارات المتقاعدة تبقى مغلقة قبل تحليل الجسم كما كانت.

تُنظف السلال المنتهية عند أول وصول بعد مرور نافذة، وتُحذف الأقدم إنشاءً عند بلوغ الحد؛ كل خريطة لا تتجاوز عشرة آلاف IP، أي عشرين ألف مدخل بين خريطتي العام والدردشة، إضافة إلى سلة طوارئ واحدة. البيانات هنا عدادات وعناوين تشغيلية مؤقتة في الذاكرة، وليست إجابات أو تقارير أو محتوى محادثة محفوظاً.
