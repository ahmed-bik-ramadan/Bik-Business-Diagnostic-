# تسجيل محادثة مؤهلة

بعد كل محادثة واتساب، دوّن صفًا في سجلّك اليدوي. ضع «نعم» إذا ناقش صاحب النشاط حاجة تخص شركته، وارتبطت المحادثة بعرض مناسب واتُّفق على خطوة تالية. في غير ذلك اختر «لا».

عند غياب صفحة المصدر أو العرض اكتب «غير محدد». اجعل الملاحظات مختصرة، مثل الخطوة التالية المتفق عليها، وتجنّب تدوين الأسماء وأرقام الهواتف أو نسخ نصوص المحادثات.
